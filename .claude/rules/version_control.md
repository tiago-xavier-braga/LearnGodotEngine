# Version Control







## Commits
### Pattern

```jsx
<type>: <description>
```

### Comment type

1. **feat-code**: a new feature that involves the creation of a peace of code or script.
2. **refactor**: a code change that neither fixes a bug nor adds a feature.
3. **fix**: a code change that fix a know bug.
4. **scene**: used when a scene is created or modified.
5. **asset**: used when you have the creation or modification of assets that is not a script nor a scene, like 3D models, audios, prefabs, timelines, scriptable objects, etc.
6. **maintenance**: used when you have changes that is maintenance related, like deleting unused assets, updating a package to avoid problems, organizing folders or files, etc.
7. **external-asset**: used when you have the addition or update of a external asset. Assets created by Haus contractors or by internal members using others softwares, must not be considered as external asset.
8. **build**: used when the changes is related to project builds, like updating things in ```Build Settings``` or ```Player Settings```, etc.
9. **docs**: creation or changes of documentation files.
